# All Courses Tabbed Navigation
This script creates tabs for the four course sections on the all courses page for a user (https://*.instructure.com/courses). Four tabs are created: Current Enrollments, My Groups, Past Enrollments, and Future Enrollments. This make navigating the all courses page much easier and quicker for users. You will also need to add the CSS file to your Canvas CSS themes file for the tabs to work. Currently, the CSS file is namespaced to my university. You can come up with your own namespace and edit the CSS and JS file or leave it as is. 

This script can also be used in conjunction with James Jones's sort and filter script on the all courses page: https://github.com/jamesjonesmath/canvancement/tree/master/courses/all-courses.
