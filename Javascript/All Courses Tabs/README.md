# All Courses Tabbed Navigation
This script creates tabs for the four course sections on the all courses page for a user (https://*.instructure.com/courses). Four tabs are created: Current Enrollments, My Groups, Past Enrollments, and Future Enrollments. This make navigating the all courses page much easier and quicker for users.

This script can also be used in conjunction with James Jones's sort and filter script on the all courses page: https://github.com/jamesjonesmath/canvancement/tree/master/courses/all-courses.
